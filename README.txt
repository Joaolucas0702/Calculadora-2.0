# Calculadora de Despesas Imobiliárias

Calculadora completa para estimar custos em:
- Financiamentos imobiliários
- Compras à vista
- Empréstimos com garantia de imóvel

## Funcionalidades
✔ Cálculo de ITBI, registro, escritura e lavratura  
✔ Suporte a múltiplas cidades  
✔ Descontos para primeiro imóvel  
✔ Três modos de operação  

## Tecnologias
- Python 3.8+
- Streamlit (interface)
- Pandas (cálculos)

## Como Usar
1. Clone o repositório
2. Instale as dependências
3. Execute `streamlit run app.py`
